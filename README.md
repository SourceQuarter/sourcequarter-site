# sourcequarter.com

Static company website for Source Quarter LLC, hosted on GitHub Pages (free, public repo).

- Plain HTML + CSS, no build step. Edit and push to `main` → live in ~1 minute.
- Custom domain in `CNAME`; DNS in AWS Route 53.
- Logo source: `SourceQuarter/hq/brand`.

Preview locally:

```sh
python3 -m http.server 8000   # then open http://localhost:8000
```
